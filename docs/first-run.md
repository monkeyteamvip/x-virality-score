# First run (personal board)

For marketplace importers and any new operator:

1. Ask for **X handle** and **watchlist** accounts
2. Write `config/watchlist.json`
3. Scaffold the dashboard from `board/`
4. Help publish to **their** github.io URL
5. After each digest, refresh **that** board

Never default them onto https://monkeyteamvip.github.io/kiosa-board/ — that URL is demo/example only.
